# 🍃 Sobre o Projeto

O **Cannoli Dashboard** é uma plataforma moderna de gestão e visualização de dados desenvolvida pelo time **CT Devs**.

A aplicação foi construída utilizando tecnologias modernas do ecossistema frontend com foco em:

* Performance
* Escalabilidade
* UX/UI moderna
* Componentização
* Responsividade
* Visualização de métricas em tempo real

O projeto centraliza operações administrativas e estratégicas através de dashboards interativos, tabelas dinâmicas, gráficos e ferramentas de gestão.

# ⚙️ Instalação Local

## Clone o projeto

```bash
git clone https://github.com/Vinishireis/cannoli-dashboard.git
```

## Acesse a pasta

```bash
cd cannoli-dashboard
```

## Instale as dependências

```bash
pnpm install
```

## Rode o projeto

```bash
pnpm run dev
```
